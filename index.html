依據 /pv-performance-diagnosis 技能規範，整站合計數據可診斷全場光學衰退與感測器故障；但若要進一步進行「各變流器同儕比對 (P2P Monitor Level)」、「MPPT 多路電流差異排查」與「單串斷路/熔絲熔斷自動標記」，必須取得逐台變流器的高頻電氣數據與竣工電氣圖紙。

📊

1. 各變流器逐台高頻遙測日誌 (Inverter-Level Time Series, 1-min / 5-min)

包含全場每台變流器（INV-01 至 INV-N）的 1 分鐘或 5 分鐘時間序列數據：
• 交流側：三相交流電壓 ($V_{ac}$)、三相電流 ($I_{ac}$)、有功功率 ($P_{ac}$)、功率因數 (PF)
• 直流側：每路 MPPT 之直流電壓 ($V_{mppt1..N}$) 與直流電流 ($I_{mppt1..N}$)
• 狀態與告警：變流器內部機芯溫度 ($T_{igbt}$)、運轉狀態碼、告警事件記錄 (Alarm/Fault Event Log)

必要檔案 CSV / Excel 格式 1~5 分鐘採樣 用途：UNSW P2P 同儕比對、MPPT 顯著差異、組串斷路
📐

2. 電氣竣工單線圖 (SLD) 暨模組組串串接圖 (DC String Layout)

• 竣工單線圖 (Single Line Diagram)：變流器台數、型號容量、交直流盤、升壓變壓器與電網併網點規格。
• 模組串接平面圖 (C-002 DC String Layout)：各變流器每路 MPPT 實際串接之組件型號、串數、每串片數，用以建立真實容量 (Actual DC kWp) 基準，排除 SCADA 登錄誤差。
• 直流匯流箱 (Combiner Box) 與熔絲規格：熔絲額定電流 (A) 與防雷突波器 (SPD) 型號。

必要檔案 PDF / DWG 竣工圖 用途：校正真實銘牌容量、定位斷路熔絲箱號
⛅

3. 氣象環境監測儀器規格書與 Modbus 點位表 (Register Map)

• 日射計 (Pyranometer)：儀器廠牌型號、出廠校正證書（靈敏度係數 $\mu ext{V}/ ext{W/m}^2$）、安裝傾角 (Tilt) 與方位角 (Azimuth)、水平日射 (GHI) 或斜面日射 (POA) 標籤。
• 模組背面溫度感測器 (PT100)：感測器型號、安裝位置照片、通訊協議與 Modbus Register Map，以修正夏季溫度 PR 出現負值之軟硬體溢位問題。

必要檔案 PDF 規範書 / Excel 點位表 用途：pvlib 晴空輻照度校準、IEC 61724 溫修公式除錯
🌊

4. 水面浮體水工結構圖與錨碇佈置圖 (Floating Array Civil & Mooring)

• HDPE 水面浮台配置圖：各陣列分區（北池、中池、南池）浮筒組合與走道排布。
• 錨碇鋼纜與自適應滑軌佈置：水下配重錨塊、岸邊地錨規格、滯洪池設計洪水位 (HWL)、常水位 (NWL) 與枯水位 (LWL)。
• 用途：分析 8 月汛期蓄水水深變化時，浮台位移拉扯對水下高壓直流電纜絕緣阻抗 ($R_{iso}$) 的應力影響。

建議提供 PDF / 水利圖紙 用途：水域防汛安全評估、浮台應力檢核
🛠️

5. 歷史維運工單、巡檢紀錄與台電停電通報日誌 (O&M Logs)

• 過去 12 個月模組清洗作業日誌（日期、耗水量、清洗區域）。
• 無人機紅外線熱成像巡檢報告（IR Thermography Report）與熱斑清冊。
• 台電電網檢修停電通報單、饋線跳脫記錄，用以排除外部電網因素造成的發電減損。

建議提供 PDF / Excel 工單 用途：前後對照驗證 (Validation Ratio)、熱斑老化分析
