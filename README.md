## 📋 深度性能診斷需要的明確資訊文件清單 (Required Information Documents)

依據 **`/pv-performance-diagnosis` (UNSW-Solar)** 標準性能診斷規範，現階段整站合計數據已完成全場光學衰退與感測器故障診斷；若需進一步啟動**各變流器同儕分群 (P2P)、MPPT 多路電流差異排查與單串斷路/熔絲熔斷精確定位**，系統需要以下 5 大類明確資訊文件：

### 1. 各變流器逐台高頻遙測日誌 (Inverter-Level Time Series)
- **檔案格式**：CSV / Excel 格式，採樣頻率 **1 分鐘或 5 分鐘**。
- **必要欄位**：
  - 時間戮記 (`Timestamp`)、變流器編號 (`Inverter_ID`)
  - 交流側：三相交流電壓 ($V_{ac,U}, V_{ac,V}, V_{ac,W}$)、三相電流 ($I_{ac}$)、有功功率 ($P_{ac}$)、功率因數 (PF)
  - 直流側：每路 MPPT 之直流電壓 ($V_{mppt1..N}$) 與直流電流 ($I_{mppt1..N}$)
  - 機芯溫度 ($T_{igbt}$ / 散熱片溫度)
  - 變流器即時告警事件記錄與代碼日誌 (`Alarm/Fault Event Log`)
- **解鎖之 UNSW 分析能力**：
  - `31-P2P_ShortTerm_Monitor.ipynb`：變流器級 5 分鐘同儕差分比對 (Division / Delta / Mixture)。
  - `51-SMA_MPPTs_signficant_difference.ipynb`：多路 MPPT 電流相位離散度檢驗。
  - `52-StringFault_Single.ipynb`：單組串斷路熔絲熔斷自動識別。

### 2. 電氣竣工單線圖 (SLD) 暨組串串接圖 (DC String Layout)
- **檔案格式**：PDF 掃描檔或 AutoCAD DWG 竣工圖面。
- **必要資訊**：
  - 竣工單線圖 (SLD)：變流器台數、廠牌型號（如 SUNGROW, HUAWEI, DELTA）、額定容量、交直流盤、升壓變壓器與併網點規範。
  - 組串串接平面圖 (C-002 DC String Layout)：各變流器每路 MPPT 實際串接之組件型號、串數、每串片數，用以建立**真實銘牌容量 (Actual DC kWp)**，消除 SCADA 登錄容量誤差。
  - 直流匯流箱 (Combiner Box) 與直流熔絲 (Fuse) 額定規格 (A)。
- **解鎖之分析能力**：精準標定發電落後變流器背後所對應之實體浮筒區塊，指引維運直達故障箱。

### 3. 氣象環境監測儀器出廠校驗書與 Modbus 點位表 (Register Map)
- **檔案格式**：PDF 儀器規格書 / Excel Modbus 點位暫存器表。
- **必要資訊**：
  - 日射計 (Pyranometer) 廠牌型號、出廠校正係數（靈敏度 Sensitivity $\mu\text{V}/(\text{W/m}^2)$）、安裝傾角 (Tilt) 與方位角 (Azimuth)、水平日射 (GHI) 或斜面日射 (POA) 標籤。
  - 模組背面溫度感測器 (PT100/熱電偶) 安裝位置、通訊協議與 Modbus Register Map 點位表。
- **解鎖之分析能力**：
  - `22-ClearSky_Day.ipynb`：以 pvlib 晴空模型精準擬合五甲尾滯洪池理論日照。
  - 根治 6~9 月溫度 PR 出現負值 (-135.6%) 之軟硬體暫存器溢位錯誤。

### 4. 水面浮體水工結構圖與錨碇佈置圖 (Floating Array Civil & Mooring)
- **檔案格式**：PDF 水工或土木結構圖紙。
- **必要資訊**：
  - HDPE 水面浮筒陣列分區圖（北池、中池、南池浮台組合與走道排布）。
  - 岸邊自適應滑軌錨定鋼纜、水下配重錨塊規格。
  - 滯洪池設計洪水位 (HWL)、常水位 (NWL) 與枯水位 (LWL)。
- **解鎖之分析能力**：分析 8 月防汛蓄水水深劇增時，浮台位移拉扯對水下高壓直流電纜絕緣阻抗 ($R_{iso}$) 的應力影響，排查防水氣滲漏隱患。

### 5. 歷史維運工單、巡檢紀錄與台電停電通報日誌 (O&M Logs)
- **檔案格式**：PDF / Excel 工單紀錄。
- **必要資訊**：
  - 過去 12 個月模組清洗作業日誌（日期、耗水量、清洗區域）。
  - 無人機紅外線熱成像巡檢報告（IR Thermography Report）與熱斑清冊。
  - 台電電網檢修停電通報單、饋線跳脫記錄。
- **解鎖之分析能力**：前後對照驗證清洗效果恢復比值 (Validation Ratio)；以機器學習 (`43-1-Recurring_Binary_ML.ipynb`) 分類固定遮蔽、熱斑老化與非預期跳機。

## 🔬 UNSW-Solar 故障特徵識別與診斷剖析

根據澳洲新南威爾斯大學 (UNSW-Solar) 性能診斷演算法，本電廠之異常特徵歸納為三大關鍵發現：

```
┌────────────────────────────────────────────────────────────────────────┐
│ UNSW 遙測物理特徵比對 (Empirical Decoupling: 8/11 ~ 11/10)              │
├────────────────────────────────┬───────────────────────────────────────┤
│ 直流工作電壓 (V_dc)             │ 675.6V (8月) → 696.3V (11月) (低溫攀升)│
│ 逆變器轉換效率 (Inverter Eff)   │ 97.27% → 97.33% (恆定維持高水準)       │
│ 光生電流比 (I_dc / Irradiance) │ 6.434 A/(W/m²) → 5.594 A/(W/m²) (-13.1%)│
│ 全場晴空日 PR                   │ 83.93% (8月中) → 75.32% (11月上旬)     │
└────────────────────────────────┴───────────────────────────────────────┘
                                 │
                                 ▼
                     確診：水面浮體光學衰退 (Optical Loss)
               防汛退水泥水附著 ＋ 秋冬季無雨期粉塵積累
```

### 1. 排除之假設清單 (Hypotheses Excluded)
- ❌ **非台電調度降載 (Curtailment)**：全期 92 天共 8,832 筆「電力控制比率」均為 100.0%，台電未實施遙控壓降。
- ❌ **非逆變器截割 (Clipping)**：全期最高 AC 功率 4,233.5 kW（額定比 84.7%），晴空日功率呈標準拋物線，無削峰。
- ❌ **非組串保險絲熔斷**：電壓無開路突升，電流呈連續漸進式下降而非台階式階躍。
- ❌ **非電網過壓跳機**：交流妥善率達 99.43%，無保護解聯。
- ❌ **非 PID 或接地漏電故障**：直流工作電壓隨秋冬降溫由 675.6V 逆勢走高至 696.3V（涼天達 710V~735V），完全符合結晶矽負溫度係數特徵。

### 2. 環境感測器破產危機與修復進展
- **日射計通訊恢復穩定**：10/02~10/04 曾經歷連續通訊中斷（192 筆 NaN），但自 10/14 至 11/10 連續 28 天取樣率維持 100%（Null count = 0），確認通訊硬體已恢復正常。
- **溫度修正 PR 負值崩潰**：2026/06~09 連續 4 個月溫度修正 PR 顯示負值（-5.2% ~ -135.6%），證實模組溫度傳感器 (PT100) 於夏季發生數值溢位或斷線，導致 IEC 61724 溫修演算法失效，須進行 Modbus 暫存器重新校驗。

## 🛠️ 8D 異常問題解決與落實行動 (D0~D8)

- **D0 立案反應**：SCADA 演算法自動偵測立案；評估水面浮體 1000V DC 絕緣阻抗與防汛浮台纜繩張力，確認無立即急停機危險。
- **D1 RACI 團隊**：成立跨職能小組，由進金生數據小組（A）、南部工務所（R）、SCADA 工程師（C）與中租窗口（I）協同執行。
- **D2 問題量化 (5W2H)**：鎖定 10~11 月落塵光學衰退（單位光生電流衰退 13.1%~15.8%）與全年度 24.7 萬度發電缺口。
- **D3 暫時圍堵**：24hr 內重整日射計 RS-485 訊號線與 Modbus 埠；48hr 內完成全場 5 MWp 無人機熱成像空拍航測；完成 300 kWp 示範區水槍試洗。
- **D4 根本原因**：確診防汛退水泥水附著、秋季粉塵沈積、氣象站突波干擾及 SCADA 負值溢位容錯缺失。
- **D5 永久對策**：
  1. 採納**「無人水面遙控清洗船深層除垢」**（預算 48 萬元/次，年化發電增益 120.3 萬，回本期僅 4.8 個月）；
  2. 採納**「氣象站 RS-485 光電隔離中繼器與工業 PT100 模組升級」**（預算 12.5 萬元）。
- **D6 效果驗證門檻**：清洗後連續 7 個晴空日追蹤：$I_{DC}/G \ge 6.35 \text{ A}/(\text{W/m}^2)$，PR 穩定恢復至 $\ge 82.5\%$ 作為結案標準。
- **D7 防止再發制度化**：修訂 `SOP-MOW-014 水面滯洪池光電專屬清洗規範`，明定每年 10 月上旬防汛結束強制全場水面清洗；增設 SCADA 日射中斷 3 筆自動告警與 $I/G$ 偏離 10% 智能派工。
- **D8 結案增益**：20 年累計折現淨增益達 **+NT$ 1,515 萬元**，專案內部報酬率推升 **+45 bps**。
