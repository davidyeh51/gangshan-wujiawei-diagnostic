## 🔬 UNSW-Solar 故障特徵識別與診斷剖析

根據澳洲新南威爾斯大學 (UNSW-Solar) 性能診斷演算法，本電廠之異常特徵歸納為三大關鍵發現：

```
┌────────────────────────────────────────────────────────────────────────┐
│ UNSW 遙測物理特徵比對 (Empirical Decoupling)                           │
├────────────────────────────────┬───────────────────────────────────────┤
│ 直流工作電壓 (V_dc)             │ 676.2V → 680.8V (正常平穩，秋季微升)   │
│ 逆變器轉換效率 (Inverter Eff)   │ 97.27% → 97.33% (維持超高水準)        │
│ 光生電流比 (I_dc / Irradiance) │ 6.51 A/(W/m²) → 5.49 A/(W/m²) (-15.6%)│
│ 全場晴空日 PR                   │ 84.23% (7月) → 73.25% (10月) (-11.0%) │
└────────────────────────────────┴───────────────────────────────────────┘
                                 │
                                 ▼
                     確診：水面浮體光學衰退 (Optical Loss)
               防汛退水泥水附著 ＋ 秋季無雨期粉塵積累
```

### 1. 排除之假設清單 (Hypotheses Excluded)
- ❌ **非台電調度降載 (Curtailment)**：全期 92 天共 8,832 筆「電力控制比率」均為 100.0%，台電未實施遙控壓降。
- ❌ **非逆變器截割 (Clipping)**：全期最高 AC 功率 4,233.5 kW（額定比 84.7%），晴空日功率呈標準拋物線，無削峰。
- ❌ **非組串保險絲熔斷**：電壓無開路突升，電流呈連續漸進式下降而非台階式階躍。
- ❌ **非電網過壓跳機**：交流妥善率達 99.43%，無保護解聯。

### 2. 環境感測器破產危機
- **日射計 (Pyranometer) 封包遺失**：2026/09/20、10/03、10/04 連續全天 100% 遺失（96筆 NaN），10/02 (46筆)、09/21 (41筆) 遺失，造成監控 PR 誤判為 102.8% 虛高或 0% 破表。
- **溫度修正 PR 負值崩潰**：2026/06~09 連續 4 個月溫度修正 PR 顯示負值（-5.2% ~ -135.6%），證實模組溫度傳感器 (PT100) 於夏季發生數值溢位或斷線，導致 IEC 61724 溫修演算法失效。

## 🛠️ 8D 異常問題解決與落實行動 (D0~D8)

- **D0 立案反應**：SCADA 演算法自動偵測立案；評估水面浮體 1000V DC 絕緣阻抗與防汛浮台纜繩張力，確認無立即急停機危險。
- **D1 RACI 團隊**：成立跨職能小組，由進金生數據小組（A）、南部工務所（R）、SCADA 工程師（C）與中租窗口（I）協同執行。
- **D2 問題量化 (5W2H)**：鎖定 10 月落塵光學衰退（單位電流短少 15.6%）與年化 40.6 萬度發電缺口。
- **D3 暫時圍堵**：24hr 內重整日射計 RS-485 訊號線與 Modbus 埠；48hr 內完成全場 5 MWp 無人機熱成像空拍航測；完成 300 kWp 示範區水槍試洗。
- **D4 根本原因**：確診防汛退水泥水附著、秋季粉塵沈積、氣象站突波干擾及 SCADA 負值溢位容錯缺失。
- **D5 永久對策**：
  1. 採納**「無人水面遙控清洗船深層除垢」**（預算 48 萬元/次，回本期僅 3.4 個月）；
  2. 採納**「氣象站 RS-485 光電隔離中繼器與工業 PT100 模組升級」**（預算 12.5 萬元）。
- **D6 效果驗證門檻**：清洗後連續 7 個晴空日追蹤：$I_{DC}/G \ge 6.35 \text{ A}/(\text{W/m}^2)$，PR 穩定恢復至 $\ge 82.5\%$ 作為結案標準。
- **D7 防止再發制度化**：修訂 `SOP-MOW-014 水面滯洪池光電專屬清洗規範`，明定每年 10 月上旬防汛結束強制全場水面清洗；增設 SCADA 日射中斷 3 筆自動告警與 $I/G$ 偏離 10% 智能派工。
- **D8 結案增益**：20 年累計折現淨增益達 **+NT$ 2,154 萬元**，專案內部報酬率推升 **+63 bps**。
